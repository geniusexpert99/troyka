# Самоцветики — Три в ряд

Самостоятельная игра на HTML, CSS и JavaScript без внешних зависимостей.

## Запуск

Откройте `dist/index.html` в браузере. Установка и сборка не требуются.

Для локального HTTP-сервера можно выполнить `python3 -m http.server 4173 --directory dist` и открыть http://localhost:4173.

## Правила

- Выберите самоцвет, затем соседний по горизонтали или вертикали.
- Линии из 3 и более одинаковых камней удаляются. Каждый удалённый камень даёт 10 очков; камень на пересечении линий считается один раз.
- Если совпадения не появились, обмен отменяется.
- После удаления камни опускаются, сверху появляются новые. Каскады продолжаются до стабильного поля.
- Начальное поле не содержит совпадений и имеет доступный ход. Если ходы закончились, поле обновляется с сохранением счёта.
- «Новая игра» сбрасывает счёт и поле, включая безопасный перезапуск во время анимации.
- Стартовый экран ведёт через шесть этапов: новые локации открываются за 300, 750, 1 400, 2 300 и 3 500 очков; финальный рубеж — 5 000 очков.
- После финального рубежа появляется экран завершения с результатом и рекордом. Рекорд сохраняется между запусками в браузере.
- Звук включается кнопкой с динамиком: выбор, обмен, откат, совпадения и новые этапы имеют отдельные эффекты; тихий фон и настройка включения создаются и сохраняются в браузере.

Управление: мышь, касания или клавиатура (Tab, стрелки, Enter/Пробел, Escape).

## Структура

- `dist/index.html` — стартовый экран, игровое поле и финальный экран.
- `dist/styles.css` — адаптивная сетка и анимации.
- `dist/core.js` — чистые правила: совпадения, обмен, доступные ходы, генерация и падение.
- `dist/game.js` — состояние игры, управление, очки, каскады, этапы и Web Audio.
- `dist/assets/gems.png` — общая текстура шести самоцветов с готовыми бликами и тенями; `art/gems.svg` — редактируемый векторный оригинал.
- `tests/core.test.cjs` — проверка правил, включая длинные линии, пересечения, падение и каскады.
- `tests/game.test.cjs` — проверка управления, отмены обмена, последовательных ходов и перезапуска во время анимаций.

## Проверка

`node --test tests/*.test.cjs`

Анимации обмена, отката, исчезновения и падения выполняются через Web Animations API; игровая логика ждёт их завершения. Перезапуск отменяет текущие анимации. Для уменьшения нагрузки 64 кнопки переиспользуются, выбор меняет только два камня, а переходы экранов меняют только прозрачность и положение в общей сетке постоянного размера. Частицы используют один Canvas, размер которого обновляется через ResizeObserver, а не во время комбинаций.

Для локального измерения кадров: `node tools/profile-server.cjs`. Откройте http://127.0.0.1:4173/after/ и нажмите «Играть», затем сделайте ход. Статистика показывает интервалы requestAnimationFrame и длинные задачи; диагностический скрипт не входит в опубликованную игру. Для сравнения можно передать полный SHA предыдущей версии и открыть также `/before/`. Результаты замеров описаны в `tests/performance.md`.

Готовая текстура не требует сборки. После правки векторного оригинала её можно обновить командой `node tools/rasterize-gems.cjs` в среде с установленным `sharp`.

Если браузер поддерживает WebMCP, игра также предоставляет `read_game`, `start_new_game` и `swap_gems`. В остальных браузерах управление работает обычным образом.
